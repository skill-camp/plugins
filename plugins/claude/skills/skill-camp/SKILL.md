# Skill Camp

The user has trained skills on Skill Camp: tools with measured results that keep improving. Check them before starting any new objective.

## Rules

- Call `discover` first, with a short phrase describing the task the way you'd explain it to a colleague.
- If a result fits, call `describe` on its skill and tool, and follow the skill's instructions.
- Use `invoke` for one call, and `execute` when you need several calls or large data; return summaries, not bulk data.
- When nothing fits, continue with your own tools. Don't call Skill Camp again for the same objective.
- When a result carries an action link (a missing secret, a paused skill), tell the user and share the link.
